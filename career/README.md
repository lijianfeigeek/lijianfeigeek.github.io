# 职业生涯照片墙素材目录 (Career Moments Photos)

本目录专门用于存放“关于我”页面（`/post/about`）拍立得时间轴照片墙的展示图片。

### 常用推荐文件名对应关系：
| 文件名 | 对应时期/阶段 | 建议格式与比例 | 说明 |
| :--- | :--- | :--- | :--- |
| `qunar.jpg` | 2014-2016 · 北京 · 去哪儿网 | JPG / PNG / WebP，4:3 或 16:9 | 办公区、团队合照、技术分享或工牌等 |
| `tencent.jpg` | 2018-2021 · 深圳 · 腾讯 | JPG / PNG / WebP，4:3 或 16:9 | 腾讯大厦、开心鼠口语秀、工卡或开源纪念 |
| `daraz_hackathon.jpg` | 2022-2024 · 新加坡 · Daraz (Alibaba) | JPG / PNG / WebP，4:3 或 16:9 | Daraz 黑客松夺冠现场、答辩或团队合影 |
| `indie_apps.jpg` | 2023-2025 · 全球 · 独立开发 | JPG / PNG / WebP，4:3 或 16:9 | 独立出海、App Store 上线作品矩阵或工作桌面 |
| `singapore_life.jpg` | 2024-至今 · 新加坡 · 极客生活 | JPG / PNG / WebP，4:3 或 16:9 | 新加坡生活足迹、滨海湾或日常漫步 |
| `ai_agent.jpg` | 2025-2026 · 前沿 · AI 智能体探索 | JPG / PNG / WebP，4:3 或 16:9 | 个人 AI 工作流、极客硬件或智能体实战 |

> [!TIP]
> **如何替换照片？**
> 1. 将你的照片重命名为上述文件名（如 `qunar.jpg`、`tencent.jpg` 等）直接放入本目录覆盖对应文件；
> 2. 如需新增照片或修改标题，直接在 `posts/about.md` 中复制/修改对应的 `<div class="polaroid-card" ...>` 结构；
> 3. 运行自动发布指令即可极速更新上线。
