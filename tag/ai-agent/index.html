在 macOS 平台上进行网络诊断与通信排障时，长久以来我始终在两类截然不同的工具生态间艰难权衡。一端是以 Wireshark、tcpdump 为代表的经典报文级抓包工具，它们拥有极其广博的协议解析生态，但其交互哲学完全围绕原始数据包流展开，面对动辄数十万个离散的 ACK 确认与窗口更新帧，排障过程极度依赖复杂的过滤表达式与脑内时序重构，更无法直接感知“究竟是 Mac 上的哪个 App 发起了这次请求”；另一端是以 Proxyman、Charles 为代表的 HTTP 代理调试工具，它们虽然具备直观的应用级体验，但核心依赖根证书伪造与中间人拦截（MITM），不仅完全无法触达非 HTTP(S) 的原生传输层（如原始 TCP/UDP、DNS、STUN、VPN 隧道与 QUIC 底层通信），更对系统网络栈造成了侵入式篡改。

在 Reddit 的 r/homelab 社区里，有一类帖子永远占据着全站顶流：那些黑底发光、细节纤毫毕现、信息密度爆炸的家庭实验室全景拓扑图。从最上游的光猫、防火墙、核心交换机，到下游每个物理网口的协商线速，再到 Proxmox 虚拟化集群内的 LXC 容器、Traefik 域名路由，甚至 TrueNAS 存储池中每一块 HDD/SSD 的物理盘位与 VDev 布局——每一张都宛如工业级数据中心的操作手册。然而，绝大多数人为了画出这样一张图，往往需要在 Draw.io、Visio 或 Illustrator 里耗费整整一个周末，手动拖拽成百上千条贝塞尔曲线与矩形，而一旦内网某台虚拟机改了个 IP 或新增了一个 VLAN，整张图的排版维护便瞬间沦为一场灾难。

2026-11-09 19 min read # iOS开发 # 逆向工程 # AI Agent # 架构设计 # 自动化测试 # MCP

长期以来，在移动自动化与终端控制领域，iOS 始终是一座被严密沙盒死死锁定的“孤岛”。相比于 Android 生态中成熟的 ADB 调试桥、无需 Root 的 Shizuku 框架以及无障碍服务（AccessibilityService），iOS 上的自动化方案长期在两个极端之间摇摆：要么依赖越狱生态下的 Frida、Cydia Substrate 等侵入式 Hook 工具，但面对近年来 Apple 持续收紧的沙盒机制与金融风控检测，越狱设备的生存空间被极度压缩；要么依赖必须常驻外接 Mac 宿主机的 WebDriverAgent（WDA）或 go-ios，设备一旦拔掉数据线或脱离桌面环境，整套自动化管线瞬间瘫痪。

近期，知名网络与底层架构开发者 nekohasekai（同时也是著名网络框架 sing-box 的缔造者）开源了通用 iOS 自动化平台 Swipt。这一项目以极其惊艳的逆向工程构思与网络协议工程，彻底打破了“无越狱就无法在端内实现深度自省与自主控制”的技术宿命。Swipt 既不依赖越狱，也无需外接电脑常驻，它完全运行在 iPhone/iPad 本地端侧，通过精巧的本地 TUN 环回反射隧道接入 Apple 核心开发者服务，结合 JavaScriptCore 运行时与 Model Context Protocol（MCP），让移动端 AI Agent 获得了毫秒级、强类型的终端驾驭能力。本文我将深入 Swipt 的源码与系统内核交互细节，全面拆解其分层架构、环回配对破壁、特权守护进程联动以及在智能体时代的范式革新。

2026-11-09 23 min read # ProxyCrab # Lua # 安全工程 # MITM # 网络调试 # AI Agent # Rust

在将大语言模型与自主智能体（AI Agent）引入日常研发流后，我经历了一段极度矛盾的调试阵痛期：当我在终端里吩咐 Agent“排查当前登录接口偶发的 500 报错并给出修复方案”时，Agent 能够迅速阅读代码仓库、梳理调用栈甚至定位潜在的空指针异常；但只要问题涉及客户端与服务端之间真实的网络交互、鉴权交换或长连接双向帧，Agent 瞬间就变成了被蒙上双眼的盲人。它既无法感知设备当前发出的物理 HTTP 流量，也无法验证自己编写的修复脚本是否真实奏效。

随着大语言模型（LLM）与多模态模型（VLM）在推理与工具调用能力的飞跃，移动端操作系统上的“自主代理”（Mobile Agent）成为了极客圈最热门的方向之一。然而，长期以来市面上绝大多数 Android 端侧自动化方案——无论是早期的 AutoJS、Appium 脚本流派，还是近年来在学术界颇为火热的各类基于多模态截屏与无障碍服务的 Agent 实验项目——在真实日常使用中几乎都会沦为无法落地的“工程玩具”。其根本痛点在于：它们无一例外都要霸占手机的物理主屏幕。只要 Agent 开始执行任务，你的手机屏幕就会疯狂闪烁、按键自动翻滚、软键盘频繁弹出；你既不能回复微信，也不能浏览网页，稍有误触就会导致 Agent 的执行流彻底崩溃。
