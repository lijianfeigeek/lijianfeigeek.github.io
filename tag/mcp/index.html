穿透 iOS 闭源黑盒：iOSDecryptHub 的运行时加解密拦截、内存脱壳与 MCP 逆向架构实战
2026-10-19 20 min read # iOS逆向 # 运行时安全 # 加解密审计 # 内存脱壳 # Capstone # MCP

在移动安全审计、私有协议分析以及 iOS 应用逆向工程中，最令人头疼的往往不是越狱环境的对抗，而是应用层无处不在的“黑盒加密”。即便我费尽周折绕过了 TLS 证书绑定（SSL Pinning），在抓包工具中截获的网络负载往往依然是一长串面目全非的 Hex 或 Base64 密文字符串。面对经过高强度混淆、去除了符号表甚至内嵌了自研加解密逻辑的 Mach-O 二进制，传统的 Frida 动态插桩往往受制于繁琐的环境配置、脆弱的流式钩子维护以及系统反调试机制的频频阻击。

最近开源的 iOSDecryptHub 给出了极具野心的解决方案。它不仅是一个基于 fishhook 的单一 C/Objective-C 运行时动态库（decrypt_helper.dylib），能够全方位拦截 iOS 底层加解密、网络、文件、Keychain 与动态库加载行为，并提供零依赖的内嵌 Web 控制台与内存流式砸壳；更颠覆性的是，它在宿主进程内部直接嵌入了 Model Context Protocol（MCP）服务器，配合 PC 端的 idh 网关，让 Claude Code、Codex 等 AI Agent 能够直接拥有刺入 iOS 进程内部的“透视眼”与“反汇编手术刀”。我通读了它的全部源码并进行了真机实测，本文将深度剖析其核心架构与工程落地细节。

打破跨端孤岛：从 Codex 镜像操控到 AndroMeld 原生 MCP 驱动 Android 的系统级演进
2026-09-25 16 min read # 系统架构 # macOS # AI Agent # Android # MCP

随着前沿大模型与自主代理（Autonomous Agent）技术从单纯的代码补全走向全系统接管，“Computer Use”（计算机视觉环境交互）正在迅速打破桌面操作系统的边界。知名独立创作者归藏（op7418）近期展示了一个引发热议的自动化技巧：利用 Codex / Claude 的 Computer Use 视觉控制功能，直接接管 macOS 上的 iPhone 镜像窗口，从而以极低的时延和近乎零风控的安全性自动化操作手机内的系统设置与移动端 App。这一玩法揭示了端侧自动化的一大核心痛点——与其在受限的移动端环境逆向逆向协议或注入风险脚本，不如借由桌面操作系统的系统级桥接通道，让物理设备充当安全沙箱。

在当今的软件研发团队中，项目与任务管理系统正面临着前所未有的双重割裂：

2026-09-12 19 min read # YourDesk # 远程桌面 # WebRTC # Go语言 # AI Agent # MCP # 原创

在多端协同与混合办公成为常态的今天，远程桌面（Remote Desktop）早已是每位工程师桌面上的标配基础设施。然而，无论是老牌商业闭源软件（如 TeamViewer、AnyDesk、ToDesk）日益严苛的弹窗限制与商业授权壁垒，还是开源领域的经典方案（如 RustDesk、VNC、RDP），它们的核心设计哲学都默认锚定在“人类眼手交互”这一单一维度——即人类坐在屏幕前，通过肉眼观察画面并用物理键鼠操作远端系统。
